# Lumen Hopper

Full-colour Python 3 neon tide-hopper arcade for ElbowOS.

Hop a glowing orb across vertical lanes of speeding neon craft. Reach higher for score. Avoid collisions.

## Play

```bash
pip install -r requirements.txt
python3 lumen_hopper.py --play
```

Controls: Arrow keys / WASD to hop. R to reset. Esc to quit.

## Record a 9:16 reel

```bash
python3 lumen_hopper.py --record
```

Outputs LUMEN_HOPPER_ElbowOS.mp4 (15s, 1080x1920, h264).
